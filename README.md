# Artools Pigmentum

Site de vendas da caneta **Artools Pigmentum**, com um vídeo do produto que avança e volta conforme o scroll, no estilo das páginas da Apple.

Projeto desenvolvido no curso **Construindo sites estáticos com IA**, da Asimov Academy.

## Tecnologias

HTML, CSS e JavaScript, com GSAP + ScrollTrigger, Lenis e SplitType via CDN.
